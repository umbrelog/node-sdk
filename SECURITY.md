# Security Policy

## Supported versions

Security fixes are applied to the latest published `@umbrelog/sdk` release on npm.

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Email **[support@umbrelog.com](mailto:support@umbrelog.com)** with the subject line `Security:` and include:

- A description of the issue
- Steps to reproduce (if possible)
- Affected package version(s)

We will acknowledge receipt and work with you on a fix and disclosure timeline.

## API keys

Never commit Umbrelog API keys (`dl_…`) or Browser Client Tokens (`ubc_…`). Rotate any key that may have been exposed.
